# Site Monitor (FastAPI + AsyncIO)

Профессиональный сервис для мониторинга доступности сайтов. Построен на современном асинхронном стеке Python.

## Основные возможности (Фичи)
- **Асинхронный движок**: Максимальная производительность благодаря `asyncio` и `aiohttp`.
- **JWT-авторизация**: Защита API конечных точек с помощью токенов.
- **Фоновый воркер**: Встроенный воркер для регулярных проверок статуса сайтов.
- **История проверок**: Сохранение результатов каждой проверки (статус, время ответа) в базу данных.

## Стек технологий
- **FastAPI** — высокопроизводительный веб-фреймворк.
- **SQLAlchemy 2.0 (Async)** — современный ORM для работы с базой данных в асинхронном режиме.
- **PostgreSQL** — надежная реляционная база данных.
- **Alembic** — инструмент для управления миграциями.
- **Aiohttp** — асинхронный HTTP-клиент для проверки сайтов.
- **Docker & Docker Compose** — контейнеризация и оркестрация.

## Быстрый запуск

1. Склонируйте репозиторий:
   ```bash
   git clone <url>
   cd site-monitor
   ```

2. Запустите приложение с помощью Docker Compose:
   ```bash
   docker compose up --build
   ```
   *При запуске автоматически поднимется база данных PostgreSQL, применятся миграции Alembic и стартует сервер Uvicorn.*

3. API будет доступно по адресу: `http://localhost:8000/docs`

## Использование (API)

После успешного запуска перейдите по адресу `http://localhost:8000/docs`, чтобы открыть интерактивную документацию Swagger UI.

Основные сценарии использования:
1. **Регистрация и Авторизация**: Создайте пользователя (`POST /api/users/register`) и получите JWT токен (`POST /api/users/login`).
2. **Добавление мониторов**: Используйте токен для добавления сайтов на проверку (`POST /api/monitors`).
3. **Просмотр истории**: Запрашивайте историю проверок для конкретного сайта, чтобы видеть время ответа и статус-коды (`GET /api/monitors/{id}/history`).

Фоновый воркер автоматически начнет проверять добавленные сайты согласно заданным интервалам и сохранять результаты в базу данных.

## Тестирование

Проект покрыт автоматическими тестами (API, CLI, Checker). Для запуска тестов используется `pytest`.

Для запуска тестов локально (с использованием тестовой базы данных SQLite в памяти) выполните:

```bash
# Установка зависимостей, если еще не установлены
pip install -r requirements.txt

# Запуск тестов
pytest
```

Тесты включают проверку:
- Работы API-эндпоинтов
- Системы авторизации пользователей
- Корректности работы фонового воркера (чекера)
- CLI интерфейса
